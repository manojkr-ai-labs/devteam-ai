01 / SPECIFICATION & CONTEXT

SUBSYSTEM: LEASE-EVICT-DAEMON

Under sudden node drain events, lease TTL refresh timers fired concurrently with partitioned cluster membership updates. When an orchestrator triggered rebalancing before discovery settled, the eviction supervisor purged valid active locks due to an uncoordinated generation epoch check, triggering write amplification on the backing Redis ring.

CONSTRAINTS OBSERVED
  • Zero external network RPC calls permitted during recovery hook execution.
  • Eviction supervisor must verify monotonic clock epochs (clock_gettime(CLOCK_MONOTONIC)).
VERIFIED BOUNDARY

Partition boundary verified at membership.py:114. All locks held across drain remain preserved until the replacement coordinator claims the corresponding epoch generation hash.
